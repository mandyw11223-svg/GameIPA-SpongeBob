GAME IPA — PETUALANGAN SPONGEBOB

Versi ini dibuat lebih panjang:
- 3 level
- 29 koin total
- soal IPA muncul saat mengambil koin
- sistem nyawa
- skor
- checkpoint berupa restart level saat jatuh/terkena musuh
- musuh ubur-ubur
- kamera mengikuti pemain
- layar mulai, pause, menang, dan game over

Cara menjalankan:
1. Extract ZIP.
2. Buka folder GameIPA_SpongeBob_3Level di VS Code.
3. Pastikan folder assets ada.
4. Klik kanan index.html > Open with Live Server.

Kontrol:
A / ← = kiri
D / → = kanan
W / ↑ / Spasi = lompat
P = pause
